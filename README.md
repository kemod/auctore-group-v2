# ✨ Overview

Auctore Group is a modern corporate website developed to represent a premium fashion holding company.

Built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**, the website emphasizes clean design, responsive user experience, performance, and SEO best practices.

The project showcases the company's vision while introducing its fashion brands through an elegant and modern digital experience.

# 🚀 Getting Started

Clone repository

```bash
git clone https://github.com/kemod/auctore-group-v2.git
```

Move into project

```bash
cd auctore-group
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```text
http://localhost:3000
```

---

# 📦 Production Build

```bash
npm run build
```

Run production

```bash
npm start
```
